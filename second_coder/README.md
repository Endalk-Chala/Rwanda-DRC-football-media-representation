# Second coder packet

Materials prepared on 2026-11-20 for an independent second coding of the corpus. They were fixed before any second coding was done.

- `INSTRUCTIONS_for_second_coder.md`: one page of instructions.
- `codebook_v0.4_for_second_coder.md`: codebook v0.4 with the sections that name specific items and say how they were coded taken out (the change logs, the pilot cases, the amendments table and the procedure section). The amendments are restated as plain rules without cases.
- `blank_coding_sheet.csv`: 148 rows with identification only and every coding column empty. The two excluded press items and the French-language duplicate of one government release are left out. Seven rows are marked as readable only in part.

## The sample

The column `in_25_percent_sample` marks 39 rows, drawn at random within each group with a fixed seed (20261120): 10 government, 6 club, 3 Rwandan press, 4 Congolese press, 4 regional African press, 12 international press. The draw was made before any second coding existed.

## What is not here

The packet given to the second coder also holds the full text of 29 documents that the researcher supplied. Those texts are newspaper copy and are not stored in this repository. The column `text_supplied_in_packet` shows which rows they cover.

## A caution on blindness

The first coding is public in `data/` in this repository. A second coder must not open the repository. Where the second coder is an AI system with web access, blindness depends on that instruction being followed and cannot be verified from the outside; the methods section should say so.
